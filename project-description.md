# Qubbot

**La nueva forma de crear software: le hablas a tu agente, ves tu proyecto como un mapa 3D y aprendes mientras construyes.**

Crear software siempre fue escribir código que pocos entienden. Los asistentes de IA ya escriben código, pero alguien todavía tiene que entenderlo, revisarlo y saber si es seguro. Qubbot es un entorno de desarrollo con agentes pensado para personas que no programan.

## Cómo funciona

- **Lo ves.** Abres un proyecto y aparece como una ciudad 3D: cada carpeta es un edificio y cada archivo tiene su semáforo de seguridad.
- **Lo conversas.** Hablas con Qubi por chat o por voz, como en una llamada. Qubi entiende lo que quieres y le pasa el trabajo a tu agente: Claude Code, Codex, Grok u OpenCode, con tu propia suscripción.
- **Lo aprendes.** Qubi te da un recorrido del proyecto: cómo está armado, dónde está la documentación y por dónde empezar. Cada respuesta se explica en modo Vibe (palabras de todos los días) o Dev (nombres exactos).
- **Lo ves construirse.** El robot camina por el mapa hasta lo que revisa, y cada paso del agente aparece en vivo.

## La IA propone, el plano decide

- Los agentes solo actúan con las herramientas de Qubbot (MCP), nunca directo sobre tu disco.
- Un verificador fijo, no un modelo, revisa los riesgos de seguridad reales. El porcentaje de seguridad solo sube cuando el problema de verdad se arregló.
- Lo peligroso pide tu permiso, cada cambio guarda una copia para deshacer y los agentes nunca leen tus claves.

## Hecho con

Electron, three.js, Claude Code / Codex / Grok / OpenCode vía MCP, y voz con ElevenLabs o Grok Voice.
